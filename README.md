# MultiView Desktop Simulation Dashboard

Aplikasi MultiView yang dioptimalkan menyerupai **tampilan layar komputer (Desktop View)** penuh pada setiap frame-nya. 

## Keunggulan Versi Ini:
- **Resolusi & Ukuran Lebar**: Setiap kotak frame didesain memiliki area pandang yang luas (tinggi 550-620px dengan tata letak grid lebar) menyerupai monitor komputer sungguhan.
- **Simulasi Bar Alamat Browser**: Setiap frame dilengkapi dengan bilah URL bergaya browser desktop lengkap dengan ikon gembok keamanan.
- **Dukungan Dinamis**: Tetap dapat diatur kapasitas tab-nya (5, 10, 20, hingga 50 tab), lengkap dengan fitur Master URL, timer auto-reboot otomatis, serta tombol eksternal.
